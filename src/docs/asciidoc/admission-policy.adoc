== 입학 정책 (교사 검토용 초안)

=== 적용 범위

이 API는 백엔드 기능이다. 관리자 화면은 별도 구현해야 한다.

* 실제 반영: 전형별 정원, 1차 선발 배수, 타지역 비율, 수험표 안내문.
* 미리보기만 제공: 점수식 DSL. 기존 `CalculateFormScoreService`는 바뀌지 않으며
  학생 점수/합격 상태/문자/저장된 PDF를 변경하지 않는다.
* 점수 배점, F 대체/제외 규칙, 검정고시 환산표, 자격증 중복 처리, 동점자 처리 등의
  모든 하드코딩을 제거한 버전은 아니다. DSL의 실계산 연결과 원시 성적 입력 모델은 후속 범위다.

배포 전 PostgreSQL에 `scripts/add-admission-policy.sql`을 실행한다.
기존 일정에 정책 행이 없으면 기존 기본값을 읽는다. GET은 DB를 변경하지 않는다.
첫 수정 또는 선발 때 정책 행을 저장한다. 일정 ID에 연결하므로 학년도 이름을 바꿔도 정책은 유지된다.
새 일정은 기존 정책을 복사하지 않고 기존 기본값에서 시작한다.

=== 관리자 API

아래 엔드포인트는 모두 ADMIN 액세스 토큰 쿠키 인증이 필요하다.
비인증/일반 사용자에 대한 응답은 기존 관리자 인증 규칙을 따른다.

[cols="1,3,4"]
|===
|메서드 |경로 |용도
|GET |/admin/admission-policies/current |현재 일정의 정책
|GET |/admin/admission-policies?admission-year=2027 |특정 학년도 정책
|PUT |/admin/admission-policies/current |현재 일정의 전체 정책 교체
|GET |/admin/admission-policies/history?admission-year=2027 |최근 변경 이력 50개 (최신순)
|POST |/admin/admission-policies/score-preview |점수식 검증 및 샘플 계산 (저장 없음)
|===

정책 조회/수정은 기존 CommonResponse의 `data`에 아래 값을 반환한다.
이력은 `dataList`에 `id, userId, createdAt, beforePolicy, afterPolicy`를 반환한다.
전후 정책은 JSON 문자열이며 수정자 ID와 함께 같은 트랜잭션에 저장한다.

[source,json]
----
{
  "scheduleId": 1,
  "admissionYear": 2027,
  "version": -1,
  "selectionLocked": true,
  "selection": {
    "regular": 48,
    "meisterTalent": 10,
    "socialIntegration": 6,
    "nationalVeteransEducation": 1,
    "specialAdmission": 1,
    "firstRoundMultiplier": 1.3,
    "otherRegionRate": 0.5
  },
  "ticket": {
    "examinationLocation": "본교 평가장",
    "announcementLocation": "본교 홈페이지",
    "registrationLocation": "본교 행정실",
    "preliminaryMeetingNotice": "예비소집일 별도 안내 예정",
    "registrationMethod": "우편, 등기, 직접 제출",
    "lunchNotice": "점심식사 제공 안함, 개별 도시락 반드시 지참 바랍니다.",
    "requiredItems": "수험표, 컴퓨터용 사인펜, 흑색 또는 청색 볼펜 등",
    "allowedItems": "컴퓨터용 사인펜, 연필(흑색), 지우개, 샤프연필, 샤프심, 아날로그 시계(블루투스 등 통신기능 및 전자식 화면표시(LCD, LED)가 없는 시계 등",

PUT 본문에는 조회한 `scheduleId, version, selection, ticket`만 보낸다.
생략 필드를 부분 수정으로 취급하지 않는다. 최초 미저장 버전은 -1이고 저장 후 0부터 증가한다.
활성 일정이 바뀌거나 버전이 오래되면 409 `POLICY_VERSION_CONFLICT`다.
응답 버전은 다음 수정에 사용한다.

==== 선발 정책 보호

* 각 정원: 0~1000 정수. 일반+마이스터+사회통합의 합계는 1~1000.
  정원 외 두 전형은 합계에 포함하지 않는다 (기존 동작).
* 배수: 1~5. 타지역 비율: 0~1.
* 한국 시간 기준 접수 시작 이후, 원서가 하나라도 존재하거나 선발에 사용한 정책은 정원 수정 불가.
  409 `SELECTION_POLICY_LOCKED`를 반환한다. 동일 정원을 유지한 안내문 수정은 가능하다.
* 현재 원서에는 학년도 귀속이 없어 원서 존재 검사는 전체 원서 대상이다.
  따라서 이전 학년도 원서가 남아 있으면 새 일정 정원도 편집이 제한된다.
  과거 데이터를 지워 우회하지 말고, 후속 원서-학년도 귀속 설계 후 이 제한을 좁혀야 한다.
* 첫 선발 시 잠금이 영구 저장된다. 일정 시간을 뒤로 변경해도 잠금은 해제되지 않는다.
* 선발과 정책 수정은 동일 일정 행을 잠근다. 중도에 정책 일부만 바뀐 결과를 만들지 않는다.
* 사회통합 하위 분배/미달 이월/동점자/특별전형 탈락자 전환 알고리즘은 기존 그대로다.
* 1차 타지역 정원: floor(ceil(정원합계 × 배수) × 비율).
  2차 타지역 정원: ceil(정원합계 × 비율).
* 정책 조회 불가/손상 시 선발을 실패시킨다. 저장된 정책 오류를 기본값으로 숨기지 않는다.

==== 수험표 문구

장소 3개는 각 40자, 예비소집/등록 방법은 80자, 점심/필수/금지 품목은 120자,
허용 품목은 180자까지이며 공백만으로 입력할 수 없다.
HTML을 허용하지 않고 이스케이프하여 표시한다.
개별/전체 수험표에 동일하게 적용한다. 전체 출력은 한 번 읽은 안내문을 모든 학생에 사용한다.
이미 다운로드했거나 S3에 저장된 문서는 바뀌지 않는다. 새로 생성하는 수험표부터 반영된다.
긴 문구는 PDF 페이지 수를 늘릴 수 있으므로 실제 출력 확인 후 운영값을 확정한다.

=== 점수식 미리보기 v0

[source,json]
----
{
  "source": "매개변수 기본점수 = 77.5\n계산 교과 = 기본점수 + 4.8 * (학기21 + 학기22) + 14.4 * 학기31 + 정보 / 2\n출력 점수 = 반올림(교과, 3)",
  "inputs": { "학기21": 5, "학기22": 5, "학기31": 5, "정보": 5 }
}
----

응답 `data`:

[source,json]
----
{
  "valid": true,
  "outputs": { "점수": 200.000 },
  "trace": { "기본점수": 77.5, "교과": 200, "점수": 200.000 },
  "error": null
}
----

문법/계산 오류는 HTTP 200, `valid: false`, 빈 outputs/trace와 한글 error로 반환한다.
본문 필수 필드 누락/길이 위반/잘못된 JSON은 기존 요청 검증대로 HTTP 400이다.
실패한 식의 일부 계산 결과를 정상 결과로 반환하지 않는다.

==== 현재 문법

[source,text]
----
프로그램 = 정의를 줄바꿈으로 구분
정의     = ("매개변수" | "계산" | "출력") 이름 "=" 식
이름     = 한글/영문 등 문자 또는 "_"로 시작, 이후 문자/숫자/"_"
식       = 숫자 | 이름 | "(" 식 ")" | 단항연산 식 | 식 이항연산 식 | 함수
주석     = 줄 맨 앞의 "#"
----

* 입력은 숫자 맵이다. 샘플 집계값을 직접 보내며 학생 ID로 DB를 조회하지 않는다.
* 이름은 앞에서 정의한 것만 참조한다. 중복 이름/입력 덮어쓰기/순환/전방 참조는 거부한다.
* 숫자는 부호 없는 십진 리터럴로 적고 음수는 단항 `-`를 쓴다.
* 우선순위 (낮음 → 높음): `||`, `&&`, `== !=`, `< <= > >=`, `+ -`, `* /`, 단항 `+ - !`.
* 비교 결과는 1/0이고, 조건에서 0은 거짓, 그 외는 참이다.
* 함수: `조건(식, 참일때, 거짓일때)`, `최소(a,b)`, `최대(a,b)`,
  `반올림(값, 자리수)`, `내림(값)`, `올림(값)`, `절사(값)`, `절댓값(값)`.
* 조건/논리식은 단락 평가한다. 선택되지 않은 분기도 문법/이름 검증은 한다.
* BigDecimal 사용. 덧셈/뺄셈은 정확하게, 곱셈/나눗셈은 소수 12자리 HALF_UP.
  반올림도 HALF_UP (음수 중간값은 0에서 멀어짐).
  내림은 음의 무한대, 올림은 양의 무한대, 절사는 0 방향이다.
* `0`, 누락은 다르다. 누락/0으로 나누기는 오류다.
  F/미이수/해당 없음/원시 과목 목록을 숫자 0으로 자동 변환하지 않는다.
* 한도: 소스 8192자, 입력 40개, 정의 64개, 이름 40자, 토큰 2048개,
  중첩/연산 연쇄 32단계, 평가 연산 4096회, 숫자 절댓값 10^12 및 소수 12자리 이하.
* 반복/재귀/임의 함수/객체 속성/파일/네트워크/Java 호출 불가.
* 표, 문자열, 과목 목록 변환/집계, 정책 저장/게시/실점수 재산정은 아직 미지원이다.

==== 변천사 기반 예시

저장소 커밋 날짜는 적용 학년도를 의미하지 않는다.
`examples/score-policy/`의 예시는 당시 교과 산식과 출결/봉사 경계 변화의 표현 검토용이며,
그해 전체 입시 정책을 복원했다고 보장하지 않는다.

|2024 봉사 기준 변경 |f0608a93 |15/30 경계와 조건식

==== 교사 피드백 후 다음 단계

. 매개변수와 수식 중 어디까지 직접 편집할지, 오류 메시지/계산 과정이 이해되는지 확인.
. 원시 과목/학기/검정고시/자격증을 보존하는 입력 스키마와 표/집계 문법 확정.
. 학생의 학년도·불변 정책 버전 귀속 및 정책 게시/승인 절차 구현.
. 실제 기존 학생 데이터가 아닌 승인된 익명 샘플로 기존 계산기와 전수 비교.
. 절사/반올림 위치, 전형 전환, 동점 처리 승인 후 별도 PR에서 실제 계산기로 연결.
