# 인증 토큰 검증 변경 (#439)

- 로그인 입력과 쿠키 이름은 그대로 유지합니다.
- 보호된 API는 ACCESS_TOKEN, 재발급 API는 REFRESH_TOKEN만 허용합니다.
- 토큰의 uuid는 전화번호가 아니라 기존 User.uuid입니다.
- 서명, 만료, 발급 시각, UUID, 토큰 유형을 검증합니다.
- 기존 전화번호 기반 토큰은 401 INVALID_TOKEN으로 거부됩니다. 배포 시 재로그인이 필요합니다.
- DB 스키마 변경은 없습니다. 이전 서버와 혼합 배포하지 말고 전체 인스턴스를 함께 교체합니다.
- 프론트는 JWT의 uuid를 전화번호로 사용하지 않아야 하며, 인증 실패 시 로그인 상태를 정리합니다.
